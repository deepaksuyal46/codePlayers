# CodePlayers full-stack app

Start with ../README.md and ../DEPLOYMENT.md. This directory contains the single Next.js frontend/backend deployment and MongoDB integration. Run npm ci, configure .env.local from .env.example, then npm run db:check. Live OTP requires your 2Factor.in key and a random OTP_SECRET.

See docs/AUTH_AND_ROLES.md for authentication and docs/DATA_IMPORT.md for the bundled 1,000-product dataset. Payments are simulated.
